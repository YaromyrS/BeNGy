# BeNGy Store Description

## App Name
BeNGy - Branch Name Generator

## Short Description
Generate consistently formatted Git branch names instantly with a global hotkey.

## Full Description
BeNGy is a lightweight Windows utility that helps developers create properly formatted Git branch names in seconds. Press Ctrl+Shift+B from anywhere, enter your ticket number and description, and get a ready-to-use branch name copied to your clipboard.

### Features
- 🚀 **Instant Access** - Global hotkey (Ctrl+Shift+B) summons BeNGy from any application
- 📋 **One-Click Copy** - Branch name automatically copied to clipboard
- ✅ **Real-time Validation** - See branch name validity as you type
- ⚙️ **Customizable Formats** - Configure prefixes, separators, and naming conventions
- 🔒 **Privacy First** - Runs entirely offline, no data collection

### Perfect For
- Developers following Git branch naming conventions
- Teams using ticket-based workflows (Jira, Azure DevOps, etc.)
- Anyone tired of manually formatting branch names
